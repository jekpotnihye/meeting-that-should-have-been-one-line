One line that could have replaced an entire pointless meeting: the
decision was already in the email, so the meeting is only the same
yes, re-presented with slides.

> The email already said yes; this meeting is just that yes, with slides.

## Run it

```sh
python3 main.py
```

The program writes the entry, and nothing else, to `/output/entry.txt`,
and prints the same entry text verbatim to stdout.
